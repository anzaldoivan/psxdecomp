# Assets

| File | What |
|---|---|
| `psxdecomp-banner.svg`, `psxdecomp-banner-dark.svg` | the README banner for light and dark themes, text as outlines |
| `psxdecomp-banner.png`, `psxdecomp-banner-dark.png` | the same at 2x, for places that do not render SVG |

The pixel D is an original drawing for psxdecomp (2026-10-02), dedicated to the public domain under CC0 1.0. Its four
hues (red, yellow, teal, blue) refer to the console's colours; it uses no PlayStation logo, Sony typeface or controller
symbol. The wordmark is set in Exo 2 (Copyright 2013 The Exo 2 Project Authors, SIL Open Font License 1.1) and
converted to outlines; the font file itself is not distributed here.

Rebuild with `tools/make_banner.py` (its docstring lists the font download and the two Python packages it needs).
